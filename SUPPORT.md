# Getting help

- **Docs and live demos:** https://bollard-ui.vercel.app. Every component page has a live preview, the install command, usage and the mistake it stops. Press `⌘K` / `Ctrl+K` to search by the mistake ("wrong amount", "leaked key").
- **Found a bug?** Open a [bug report](https://github.com/Tusharkhadde/Bollard-UI/issues/new?template=bug_report.yml).
- **Want a component?** Open a [component request](https://github.com/Tusharkhadde/Bollard-UI/issues/new?template=component_request.yml).
- **Security issue?** Follow [SECURITY.md](SECURITY.md) and report it privately.

Before opening an issue, search [existing issues](https://github.com/Tusharkhadde/Bollard-UI/issues) in case it's already being discussed.
